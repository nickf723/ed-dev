## Canonical representation

- The product rule produces `4 × 3 = 12` ordered sequences.
- When position matters, all 12 sequences are different permutations.
- When only the selected pair matters, reversing a pair changes nothing. Each unordered pair has `2!` orderings, so `12 ÷ 2! = 6` combinations.
