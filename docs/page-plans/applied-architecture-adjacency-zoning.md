## Learning contract

**Learner goal**  
Understand how architects record desired relationships among programmed spaces before committing to floor-plan geometry.

**Prior knowledge**  
Program & Area: the learner should already understand that a space program identifies required spaces and provisional areas without determining their final arrangement.

**Primary mental model**  
A set of rooms forms a relationship network. Each pair may favor proximity, remain flexible, or prefer separation. Zoning groups spaces by broader access/use patterns while adjacency describes pairwise relationships.

**Evidence of understanding**  
The learner can change one pairwise requirement and predict how the relationship diagram changes without claiming that the change determines a single correct floor plan.

**Likely misconception**  
Near means rooms must share a wall, separate means rooms cannot connect, or an adjacency matrix is already a floor plan.

## Scope

**Belongs on this page**

- pairwise adjacency intent
- near / flexible / separate relationship categories
- basic public / shared-service / staff zoning
- adjacency matrix
- bubble/relationship diagram
- distinction between relationship logic and floor-plan geometry

**Does not belong on this page**

- detailed circulation path design
- corridor width or egress calculations
- room area programming
- final floor-plan generation
- detailed privacy/acoustic performance calculations

## Interaction contract

**Primary instrument:** synchronized adjacency matrix and relationship graph for a small library program.

The learner clicks any non-diagonal matrix cell to cycle the room pair through:

1. near
2. flexible
3. separate

The symmetric relationship graph updates immediately.

Curated presets show balanced, quiet-first, and service-first design intents before free editing.

Flexible relationships omit a graph edge so important constraints remain visually dominant.

## Reference rules

- Near means convenient proximity, not necessarily a shared wall.
- Separate means buffering or controlled transition, not disconnection.
- Zones are broader groupings by access/use; adjacency is pairwise.
- A matrix describes intent and may support many valid floor plans.

## Accuracy constraints

The relationship categories are a simplified educational notation, not a universal professional standard. Different practices use different adjacency scales, symbols, and matrices. The page teaches the underlying reasoning rather than claiming one canonical matrix convention.

## Definition of done

- matrix and graph share one state
- every cell change produces an immediate visible consequence
- symmetry is preserved between A→B and B→A
- preset and edited states remain readable
- near/flexible/separate semantics are clear
- the learner cannot confuse the diagram with a final floor plan
- no matrix labels or room names clip at target widths
